# 外部链接台账 · 方案 v2（按你的新要求重做）

> 定位：后台的**外链记录本**。只记标题、封面、描述，**不抓价格**。点一下直达登录后的真实商品页。
> 用途：你在多个平台卖货，卖出的在对方平台结算，所以要一个地方能跳到"我卖出的那件东西"。
> 版本：v2 · 2026-11-02

|---|---|---|

## 一、每条链接记什么

| 字段 | 说明 |
|---|---|
| 平台 | 从你加的「平台档案」里选（域名自动识别，可改） |
| 商品链接 | **登录后能直达那件商品的链接**（详情页，不是列表页/首页） |
| 标题 | 抓取或手填 |
| 封面图 | 一张主图链接（抓不到可手填） |
| 描述 | 两段：**文字** + **图片/视频链接列表**（顺序保留） |
| 备注 | 你自己写的 + 系统自动写的抓取备注（同一栏，可编辑） |
| 状态 | 在售 / 已售出（等结算） / 已下架 / 链接失效 / 待核对 |
| 上次巡检 | 每次点「打开」或巡检成功都会刷新 |

**描述为什么分两段**：你说"描述可能是图片"，实际页面里描述常常是"几句文字 + 几张长图 + 有时一个视频"。所以存成：

```
desc_text  = "30 天 100G，随用随停，不锁卡"
desc_media = [ 图1, 图2, 图3, 视频1 ]   （只存链接，顺序不乱）
```

页面展示时文字在上、图/视频按顺序在下，点图能放大、点视频能播放。**原始链接一律保存**，就算对方以后改版，你的记录还在。

> 有一点先说：对方平台的图可能有防盗链，直接在别的域名下打开会裂图。所以抓取时**顺手把图下载一份存到我们自己的存储**，缩略图用我们自己的，点开再看原图。这个我按"要做"来设计，不做的话有些平台的图会显示不出来。

## 二、三样信息怎么取（这里有个绕不过的限制）

**限制先讲明白**：我们的服务器去抓网页，是"没登录"的身份。你要的恰恰是**登录后**才看得到的东西（我卖出的、订单、商品状态）。

| 平台类型 | 服务器能抓到吗 | 怎么办 |
|---|---|---|
| 自建站 / 独立站 / 普通商城 | **能**（页面是公开的） | 服务端直接取，标题封面描述都能拿到 |
| 闲鱼 / 淘宝 / 拼多多 / 有赞等 | **不能**（要登录、页面还是 JS 渲染的） | 必须用**你浏览器里的登录态**去取 |

**"用你浏览器里的登录态去取"有两种做法，你选一个：**

### 做法 1 · 浏览器小工具（推荐，一次装好，长期省事）

在浏览器上装一个书签。你在闲鱼/淘宝打开某个商品页，点一下书签，它就把**当前页面的地址 + 标题 + 封面 + 描述里的图/视频链接**打包发回我们后台，自动落成一条记录。

- 优点：用的是你已登录的页面，**链接就是当前真实地址**，标题封面描述都是你眼睛看到的那个，不会取错。
- 代价：要装一次书签（拖一下就成，不用装插件、不用给密码）。

### 做法 2 · 复制粘贴（零安装，但每次多两步）

在商品页全选复制，粘到我们后台的框里，后台从这段内容里提出标题/图片。地址栏的链接你自己贴。

- 优点：什么都不用装。
- 代价：每次多两次复制粘贴；有些页面复制出来不带图。

**我的建议**：先做**做法 2**（保证马上能用），同时做**做法 1**（长期舒服）。两者结果进同一个库，不冲突。

## 三、链接必须"对"——这是这套东西的命门

你说得对：链接错了，结算就对不上。所以链接这块我加了三道保险：

**1. 登记时就判断"这是不是商品详情页"**

按域名规则识别：

- 闲鱼：`goofish.com/item?id=...` 是详情页；`s.2.taobao.com/list?...` 是列表页
- 淘宝：`item.taobao.com/item.htm?id=...` 是详情页；`s.taobao.com/search?...` 是搜索页
- 拼多多：`mobile.yangkeduo.com/goods.html?goods_id=...` 是详情页
- 其它平台：默认按"路径里有 id / item / goods / product / detail 之类"判断

判成列表页/首页/搜索页 → **当场提示"这不是商品详情页，结算会对不上"**，让你重贴。判不准的标"待确认"，不拦你。

**2. 存两个地址**

- `url`：商品详情页（你点「打开」用的）
- `url_backup`：**你的卖家后台该商品的管理页**（可选，填了更保险）

商品详情页有时会变，但卖家后台那条一般更稳。两个都存，主链接失效时提示你"用后台链接看看"。

**3. 打开时顺手核对**

点「打开」不只是跳转，还会：

- 刷新"上次巡检"时间
- 如果跳过去被重定向到首页/登录页 → 标"疑似失效"，问你一句"这件还在吗？"

## 四、下架 / 链接过期，怎么发现、怎么反应

这块按你的生意逻辑分**四档**，不是简单的"有效/失效"：

| 状态 | 怎么判断 | 页面表现 |
|---|---|---|
| **在售** | 页面正常打开，能看到商品 | 正常色 |
| **已售出（等结算）** | 页面出现"已卖出/已售出/交易成功"，或你自己标记 | 蓝色，**不算异常**，备注里记"已成交，等平台结算" |
| **已下架** | 页面出现"已下架/已删除/商品不存在"，或你手动标 | 灰色，不报警 |
| **链接失效** | 打不开（404/超时），或跳到首页/登录页但看不出原因 | **红色，置顶，进信息中心提醒** |

**为什么把"已售出"单拎出来**：卖出的商品在对方平台结算——商品卖出后链接通常会失效或下架，但这是**好事**，不能跟"莫名失效"一起报警，否则你会被没用的提醒淹掉。所以成交的和出问题的一定要分开。

**巡检怎么跑：**

- 服务端能抓的平台 → 后台定时探一下（比如每天一次），拿到结果自动更新状态。
- 需要登录的平台 → 服务端探不出来，改成：**你每次点「打开」时记录结果**；再配一个「一键巡检」按钮，你在浏览器登录状态下点一下，它按顺序把这几条过一遍（或让小工具逐条回报）。
- 无论哪种，只要状态变成"链接失效"，就往信息中心写一条，并在台账顶部提示"N 条链接已失效，点这里看"。

## 五、任意平台都能收录：平台档案

不再内置死名单。你自己"加平台"，每个平台一条档案：

| 字段 | 例子 |
|---|---|
| 平台名 | 闲鱼 |
| 域名 | goofish.com |
| 登录入口 | https://www.goofish.com/login |
| **我的说明（可编辑）** | 登录后到「我的闲鱼 → 我卖出的」核对；每月 1 号结算，订单以对方后台为准；商品页链接要取详情页 |
| 结算说明 | 每月 1 号，T+1 到账 |
| 取信息方式 | 浏览器端 / 服务端 |

**「我的说明」就是你要的那段"平台描述"**：随便写，可以写怎么登录、去哪看订单、多久结算、注意事项。写完之后，选中这个平台，说明就横在列表上方，随时能看到、随时能改。

平台档案还决定了：这个平台默认用哪种取法（服务端 or 浏览器端）、巡检频率。

## 六、页面（对应设计图）

- **顶部**：平台切换条（闲鱼 12 / 淘宝 8 / 拼多多 5 / 自建站 3 / + 加平台），数字是该平台下的条数。
- **平台说明卡**：显示当前平台的名字 + 你写的那段说明，右边一个「编辑说明」。
- **工具条**：搜标题/备注 + 状态下拉（全部 / 在售 / 已售出 / 已下架 / 失效 / 待核对）+ 「+ 登记链接」。
- **列表**（卡片式，因为封面图重要）：
  - 左：封面缩略图（60×60，点开看大图）
  - 中：标题 / 描述摘要（"3 张图 + 1 段文字"）/ 备注
  - 右：状态 + 上次巡检 + 「打开」「更新」（失效的那条换成「重登再看」「换链接」）
- **失效的排最前**，整行淡红底。
- **排序**：失效 → 待核对 → 最久没巡检的 → 其它。

## 七、备注里自动写什么（你说让我定）

每次抓取/巡检，自动追加一条带时间的短备注，你可删可改：

```
2026-11-02 20:12 取到：3 图 + 1 段文字｜页面含「现货」
2026-11-03 09:00 打开正常
2026-11-05 09:00 跳转到了首页（疑似下架）
```

只写**有用且能验证**的东西：取到几个图/视频、描述是文字还是图、页面上有没有"现货/包邮/已售出"这类关键词、打开结果是正常还是跳走。**不写猜测**。

## 八、权限（和现有账号体系一致）

新增 `external.*` 一组，接进你现有的权限分组网格：

`external.view` 看台账 / `external.add` 登记 / `external.edit` 改 / `external.fetch` 更新与巡检 / `external.del` 删（进回收站） / `external.export` 导出

- 平台档案的编辑属于 `external.edit`，但**只有超管能加/删平台**。
- 外链可挂分类，受 `catsScope` 限制；上级能看下级的全部，下级看不到上级的。

## 九、和现有功能联动

1. **信息中心**：新增「N 条外链失效」「张三 登记了 3 条」。
2. **回收站**：外链删除可恢复/彻底删。
3. **批量导入**：加一张「外部链接」表（平台/链接/标题/封面/描述/备注），平台是下拉。
4. **数据导出**：CSV，含所有字段。
5. **顶部提示**：有失效外链时显示"N 条外链需处理"。

## 十一、要你拍板的三件事

1. **要不要装那个浏览器书签**？（装了以后闲鱼/淘宝一键取，最省事；不装就用复制粘贴）
2. **失效提醒多久报一次**？每天一次，还是一周一次汇总？
3. **"已售出"要不要手动勾**？还是全靠页面文字判断（可能不准）。

---

## 十二、必须说清的两个边界

1. **服务器抓不到"登录后"的东西**，这不是实现问题，是平台设计如此。要拿登录后的真实信息，只能靠你浏览器里的登录态（书签或复制粘贴），这条绕不过去。
2. **我不用任何"绕过登录/破解反爬"的手段**——那既有法律风险，也会让你账号被风控甚至封号。方案里所有取数都只走"你自己已登录的页面"这条正路。
