# 外部链接台账 · 方案 v3（已定稿）

> 定位：后台的**外链记录本**。只记标题、封面、描述，**不抓价格**。点一下直达登录后的真实商品页。
> 用途：你在多个平台卖货，卖出的在对方平台结算，所以要一个地方能跳到"我卖出的那件东西"。
> 版本：v3 定稿 · 2026-11-02
>
> **三条已拍板**：① 不装浏览器书签，只用复制粘贴 ② 巡检一天一次 ③ "已售出"全靠页面文字判断（关键词表见第四节，已写全）

---

## 一、每条链接记什么

| 字段 | 说明 |
|---|---|
| 平台 | 从「平台档案」里选（域名自动识别，可改） |
| 商品链接 | **登录后能直达那件商品的详情页**（不是列表页/首页） |
| 标题 | 粘贴时自动带出候选，你确认或手改 |
| 封面图 | 一张主图（自动抓或手填） |
| 描述 | 两段：**文字** + **图片/视频链接列表**（顺序保留） |
| 备注 | 你写的 + 系统自动写的抓取备注（同一栏，可编辑） |
| 状态 | 在售 / 已售出（等结算） / 已下架 / 链接失效 / 待核对 |
| 上次巡检 | 每天一次自动巡检；你点「打开」也会刷新 |

描述存法：

```
desc_text  = "30 天 100G，随用随停，不锁卡"
desc_media = [ 图1, 图2, 图3, 视频1 ]   （只存链接，顺序不乱）
```

## 二、怎么把信息弄进来（不装书签，只走两条路）

### 路线 1 · 服务端抓（仅限公开页）

自建站、独立站、普通商城这类不需要登录的页面，后端直接读，标题/封面/描述都能拿到。

### 路线 2 · 复制粘贴（闲鱼、淘宝、拼多多等必须登录的平台，走这条）

**操作就三步：**

1. 在你已登录的商品页，`Ctrl+A` 全选 → `Ctrl+C` 复制
2. 回到后台，点「+ 登记链接」，光标放进粘贴框，`Ctrl+V`
3. 后台自动从粘贴内容里提取，你核对一下标题、补一下链接（或链接也已经带进来），保存

**为什么这样能拿到图**：浏览器复制时会把被选中内容的**富文本（HTML）**一起带进剪贴板，里面的 `<img>` 带着真实的图片地址。后台读的是这一层 HTML，不是纯文本，所以图不会丢。视频同理，能读到 `<video src>` 或封面图。

**粘贴能提到什么、提不到什么（先说清楚，别期待错）**：

| 内容 | 能不能提到 |
|---|---|
| 描述里的图片 / 视频链接 | **能**（读 HTML 里的 img/video） |
| 描述文字 | **能** |
| 商品标题 | **部分能**（页面标题不在复制范围内，通常要用正文第一行做候选，你确认一下） |
| 商品链接 | 复制正文一般不带地址栏链接，**建议你自己粘一次地址栏**（后台会记住上次粘贴的域名，帮你判平台） |
| 价格 | 不取（本就不需要） |

> 所以体验是：粘贴一下，图和描述自动进来，标题给个候选让你点确认，链接粘一下地址栏。不会让你从零手打。

## 三、链接必须"对"——三道保险

**1. 登记时判断是不是商品详情页**

| 平台 | 详情页特征 | 列表页/搜索页（会被拦） |
|---|---|---|
| 闲鱼 | `goofish.com/item?id=` | `s.2.taobao.com/list` |
| 淘宝 | `item.taobao.com/item.htm?id=` | `s.taobao.com/search` |
| 拼多多 | `yangkeduo.com/goods.html?goods_id=` | `mobile.yangkeduo.com/search` |
| 其它 | 路径含 id / item / goods / product / detail | 路径含 list / search / category / index |

判成列表页 → **当场提示"这不是商品详情页，结算会对不上"**；判不准 → 标"待确认"，不拦。

**2. 存两个地址**：商品详情页（`url`）+ 卖家后台该商品管理页（`url_backup`，可选）。主链接失效时提示你用后台链接核对。

**3. 打开时顺手核对**：刷新巡检时间；被跳回首页/登录页 → 标"疑似失效"并问你一句。

## 四、"已售出"怎么判断 —— 完整关键词表

你说全靠页面判断，所以这张表是核心。判断顺序也有讲究：**先认定成交，再认定下架**，因为卖出去的商品页往往同时写"已卖出"和"此宝贝已下架"。

### 判定优先级（从上到下，命中即停）

| 顺序 | 命中条件 | 判为 |
|---|---|---|
| 1 | 命中「已售出」词表 | **已售出（等结算）** |
| 2 | 命中「已删除/不存在」词表 | **已下架** |
| 3 | 命中「已下架/已关闭」词表 | **已下架** |
| 4 | 命中「需登录/验证」词表 | **待核对**（不是失效） |
| 5 | 命中「在售」词表 | **在售** |
| 6 | 都没有 | **保持原状态**，备注写"这次没看出状态" |

### 1. 已售出（成交，等结算）

`已售出` `已卖出` `已售完` `卖掉啦` `已经卖出` `宝贝已卖出` `此商品已售出` `交易成功` `交易完成` `已成交` `订单已完成` `买家已付款` `已拍下` `已被购买` `已下架（已卖出）` `sold`

同时出现 `库存 0` `剩余 0 件` `已抢光` 也计入这一档（卖光了）。

### 2. 已删除 / 不存在

`商品不存在` `宝贝不存在` `商品已删除` `已删除` `该宝贝已被删除` `找不到该商品` `页面不存在` `已失效` `已过期` `该商品已失效` `商品已下架或删除`

### 3. 已下架 / 已关闭

`已下架` `商品已下架` `已关闭` `已停止出售` `违规下架` `审核不通过` `已冻结` `暂不销售`

### 4. 需登录 / 需验证（判不了，不是失效）

`请先登录` `请登录` `登录后查看` `需要登录` `安全验证` `滑动验证` `人机验证` `访问验证` `验证码`

> 这一档很重要：**跳到登录页不等于商品没了**，不能报"失效"，只能标"待核对"，否则你每天都会收到假警报。

### 5. 在售

`立即购买` `马上抢` `加入购物车` `拍下` `立即下单` `剩余` `库存` `在售` `可购买`

### 6. 打不开（网络层）

- 返回 404 / 410 → **已下架**
- 超时 / 连接失败 → **链接失效**（不判下架，只报打不开）
- 被重定向到站点首页 / 登录页 → **待核对**

### 判断完写进备注（自动）

```
2026-11-03 09:00 巡检：命中「交易成功」→ 已售出，等平台结算
2026-11-03 09:00 巡检：命中「商品不存在」→ 已下架
2026-11-03 09:00 巡检：跳到登录页 → 待核对（不算失效）
2026-11-03 09:00 巡检：正常打开，命中「立即购买」→ 在售
```

## 五、巡检：一天一次

- **频率**：每天一次（默认早上第一次打开后台时跑，或后台定时任务）。
- **服务端能读的平台**（自建站等）：后台自动跑，结果直接更新状态。
- **要登录的平台**：服务端读不了，两条补充：
  1. 你每次点「打开」，顺手把这次结果记下来（正常 / 跳首页 / 跳登录）
  2. 你可以在「一键巡检」里，把当天要看的几条挨个点开过一遍，结果自动累积
- **只有"链接失效"和"已下架"才进提醒**；"已售出"不算异常（备注里记一句"等结算"）。
- 提醒方式：台账顶部一条"N 条需处理"、信息中心一条动态、顶部信息红点。

## 六、平台档案（任意平台都能加）

| 字段 | 例子 |
|---|---|
| 平台名 | 闲鱼 |
| 域名 | goofish.com |
| 登录入口 | https://www.goofish.com/login |
| **我的说明（可编辑）** | 登录后到「我的闲鱼 → 我卖出的」核对；每月 1 号结算，订单以对方后台为准；商品页链接要取详情页 |
| 结算说明 | 每月 1 号，T+1 到账 |
| 取信息方式 | 复制粘贴 / 服务端 |

**「我的说明」就是你要写的那段平台描述**：能写怎么登录、去哪看订单、多久结算、注意事项。选中平台后它就横在列表上方，随时改。

## 七、页面

- **顶部**：平台切换条（闲鱼 12 / 淘宝 8 / 拼多多 5 / 自建站 3 / + 加平台）
- **平台说明卡**：平台名 + 你写的说明 + 「编辑说明」
- **工具条**：搜标题/备注 + 状态筛选（全部 / 在售 / 已售出 / 已下架 / 失效 / 待核对）+ 「+ 登记链接」
- **列表**（卡片式）：左封面缩略图（60×60，点开放大）｜中：标题 / 描述摘要（"3 张图 + 1 段文字"）/ 备注｜右：状态 + 上次巡检 + 操作
- **失效的排最前**，整行淡红底
- **排序**：失效 → 待核对 → 最久没巡检的 → 其它

## 八、权限

`external.view` 看 / `external.add` 登记 / `external.edit` 改 / `external.fetch` 更新与巡检 / `external.del` 删（进回收站） / `external.export` 导出

- 平台档案只有超管能加/删；说明文字有 `external.edit` 就能改。
- 外链可挂分类，受 `catsScope` 限制；上级能看下级的全部。

## 九、和现有功能联动

1. 信息中心：新增「N 条外链失效」「某人登记了 N 条」
2. 回收站：外链删除可恢复/彻底删
3. 批量导入：加「外部链接」表（平台/链接/标题/封面/描述/备注），平台为下拉
4. 数据导出：CSV 全字段
5. 顶部提示：有失效外链时显示"N 条外链需处理"

## 十、实施顺序

| 阶段 | 内容 |
|---|---|
| 一 | 平台档案 + 列表 + 手动登记（含粘贴解析）+ 打开跳转 + 链接形态校验 |
| 二 | 状态关键词判定（第四节全表）+ 自动备注 |
| 三 | 一天一次巡检 + 失效提醒 |
| 四 | 权限 + 导入导出 + 信息中心/回收站联动 |

---

## 十一、边界（说清楚，不含糊）

1. **服务器读不到"登录后"的内容**，所以闲鱼/淘宝/拼多多只能靠你复制粘贴。这不是实现取舍，是平台设计决定的。
2. **状态判定靠页面文字**，平台改文案就会判错。所以：判不出来时**保持原状态不动**、只在备注里写一句，绝不瞎改。关键词表以后可以随时补。
3. 不用任何绕过登录/绕验证码的手段。
